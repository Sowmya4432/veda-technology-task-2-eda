# Veda Technology - Task 2: Exploratory Data Analysis (EDA)

## Project Overview

This project is completed as part of the Veda Technology Data Analytics Internship.

The objective of this task is to perform Exploratory Data Analysis (EDA) on the Sample Superstore dataset and identify important patterns, relationships, trends, and outliers.

## Objective

The main objectives of this project are:

- Understand the structure of the dataset
- Perform data exploration and statistical analysis
- Identify missing values and data quality issues
- Analyze distributions and relationships between variables
- Identify outliers
- Visualize important trends and patterns
- Summarize the most important findings

## Dataset

The project uses the Sample Superstore dataset.

The dataset contains information related to:

- Orders
- Customers
- Products
- Categories
- Sales
- Quantity
- Discount
- Profit
- Regions
- Dates

## Tools and Technologies

- Python
- Pandas

- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## EDA Process

The following steps were performed:

1. Imported the required Python libraries.
2. Loaded the Superstore dataset.
3. Examined the first few records.
4. Checked the number of rows and columns.
5. Examined column names and data types.
6. Checked for missing values.
7. Generated descriptive statistics.
8. Analyzed numerical and categorical variables.
9. Created visualizations to understand patterns.
10. Identified trends, relationships, and possible outliers.
11. Summarized the key findings.

## Visualizations

The analysis includes visualizations such as:

- Sales distribution
- Profit distribution
- Category-wise sales
- Region-wise performance
- Correlation heatmap
- Trend analysis over time
- Outlier analysis using boxplots

Each visualization is designed to answer a specific question about the dataset.

## Key Insights

The final notebook summarizes the three most important insights discovered during the analysis.

These insights are based on the statistical analysis and visualizations performed on the dataset.

## How to Run

1. Open the `task_2_EDA.ipynb` notebook.
2. Open it using Google Colab or Jupyter Notebook.
3. Upload the Sample Superstore CSV dataset if required.
4. Run the notebook cells from top to bottom.
5. Review the generated statistics, charts, and observations.
